# euler-app

Vite + React + MUI scaffold for the Euler Tools dashboard (tokens, swap, marketplace, assets, staking sidebar). Archived snapshot, as-is.

This tree is a **new public commit** with no git history. The original private archive is `eulertools/euler-app-archive`.

## What was built (EN)

Small frontend shell using `@eulertools/ui`. No API keys, no contract deployments in this tree. Worker-era README credited Gerardo Perrucci as original scaffold author.

## Qué se construyó (ES)

Esqueleto React/Vite del dashboard. Sin deployments.
